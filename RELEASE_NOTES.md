# Version 1.0

Released: 2026-10-15

* Demo 1 reproduces the delay-identification, adaptive-injection, and current
LOS-state reconstruction results in Fig. 5.
* Demo 2 reproduces the complete multirate platform and gimbal response in
Fig. 8.
* Demo 3 evaluates ASMO disturbance estimation and rejection.
* Demo 4 runs the integrated noncoplanar rendezvous tracking task.
* Six user-adjustable parameters are provided for reproduction and sensitivity
analysis within the configurations considered in the paper.
* The reference configuration is mapped to the paper notation, and each run
exports its effective inputs and a SHA-256 provenance manifest.
* The package uses MATLAB Runtime R2024b and does not require a MATLAB license.
* Access credentials are distributed separately and remain valid for 365 days
after first activation.
